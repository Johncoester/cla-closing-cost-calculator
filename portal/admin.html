Pricing tables: CLA settlement fee only

A pricing table is a named set of lower Settlement Fee to CLA Title & Escrow amounts, for example "Marvin's Pricing". Add a rep's email to a table and that rep's quotes, and the quotes of the clients (realtors) assigned to that rep, use the table's fees. You can also add an individual client's email: a client in a table uses it even if their rep uses another table (or none). Title insurance premiums, recording fees, taxes and every other fee never change. Anyone not in a table, and without a rep in a table, pays the standard fees.

Settlement fee sets in this table

A fee set is one group of states with its own settlement fees, for example MD + VA at $900 / $500 and FL at $1,000 / $800. A state can be in only one set. A set for All states is the fallback for any state without a set of its own. Empty boxes keep the standard fee.
